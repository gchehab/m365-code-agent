M365 Code Agent 0.6.0 — 설치 및 사용
===================================

회사 Windows PC에 VS Code와 Microsoft Edge가 설치되어 있어야 합니다.
Python, 별도 Node.js, Edge 확장, Copilot Studio, API 키는 필요하지 않습니다.

1. VS Code 왼쪽 확장 화면을 열고 오른쪽 위 … → VSIX에서 설치…를 선택합니다.
2. m365-code-agent-0.6.0.vsix를 선택합니다. 필요하면 VS Code를 다시 로드합니다.
3. 수정할 로컬 프로젝트 폴더를 엽니다.
4. 왼쪽 M365 Agent 아이콘을 선택하고 입력창 아래 '연결'을 누릅니다.
5. 전용 Edge 창에서 회사 계정으로 로그인하고 MFA를 완료합니다.
6. Copilot 채팅 화면이 열린 상태에서 VS Code에 개발 요청을 입력하고 Enter 또는 ↑를 누릅니다.

이후 요청 입력·전송·응답 수집·파일 읽기·수정은 자동입니다.
프로젝트 분석은 수동 파일 첨부 없이 주요 소스를 먼저 읽어 시작합니다.
모드 선택 없이 수정할 내용을 요청하고, 변경 승인 대기 시 적용 버튼을 누르세요.
프로젝트 점검 버튼으로 M365 연결 없이 로컬 읽기와 임시 파일 쓰기·삭제를 검사할 수 있습니다.
매 요청마다 브라우저에서 보내기/복사/붙여넣기를 할 필요가 없습니다.
전용 브라우저 창은 닫지 마세요. 일반 Edge 프로필과 별개로 로그인 상태를 유지합니다.
로그인 만료, MFA, CAPTCHA가 나타나면 직접 처리해야 합니다.

예시 요청
src/average.js가 빈 배열을 받으면 null을 반환하도록 수정하고 테스트 파일도 만들어줘.

같은 입력창에서 설명·분석·계획·수정을 요청합니다. 특정 단어 때문에 수정을 강제하지 않습니다.
작업이 끝나면 실제 적용한 파일 수를 별도로 표시합니다.
첫 요청을 보낸 후 로그인해도 요청을 보관하고 준비되면 자동 전송합니다(기본 최대 10분 대기).
실패한 요청은 VS Code 입력창으로 복원하며 새로 작성 중인 내용은 덮어쓰지 않습니다.
모델 불러오기로 현재 계정의 실제 웹 메뉴를 읽고 모델을 선택할 수 있습니다.
답변은 제목·목록·표·코드 블록으로 표시하며 코드 복사 버튼을 제공합니다.
Shift+Enter 줄바꿈, ＋ 파일로 첨부, /ask /agent /plan /review /test 단축 요청을 지원합니다.
/ask는 읽기 전용, /agent는 일반 도구 사용을 명시합니다. 변경을 강제하지 않습니다.
기본 반복 한도는 20회이며 현재 요청과 이후 남은 횟수를 표시합니다. 기존에 직접 설정한 한도는 유지합니다.
상단 시계 모양 대화 기록 아이콘에서 제목 검색·열기·이름 변경·개별/전체 삭제를 할 수 있습니다.
이름 변경·삭제는 이 작업 영역의 VS Code 기록에만 적용되며 Copilot 웹 원본과 프로젝트 파일은 유지됩니다.
기록 전환·새 대화는 현재 자동화 탭을 재사용하며 작성 중인 웹 초안이 있으면 전환하지 않습니다.
연결된 웹 대화와 로컬 대화 주소를 함께 저장합니다. 기록을 선택하면 해당 웹 대화도 엽니다.
사이드바가 보이고 작업 중이 아닐 때 5초마다 현재 연결된 웹 대화의 질문·답변을 가져옵니다.
상단 더 보기(⋯) → 웹 대화 동기화로 즉시 동기화할 수 있습니다. 가져온 기록의 수정·명령 JSON은 실행하지 않습니다.
열지 않은 웹 대화 전체 다운로드, 로컬 과거 기록 전체 업로드와 삭제 동기화는 지원하지 않습니다.
기본값은 '변경 승인'입니다. 파일별 diff를 확인한 뒤 적용 또는 거절을 선택합니다.
체크를 끄면 검증 후 자동 적용·저장합니다. 마지막 파일 수정은 되돌리기로 복원할 수 있습니다.
실행·빌드·CI 설정과 셸 스크립트는 자동 적용을 켜도 검토가 필요합니다.
명령 승인 카드에서 이번 요청과 이전 요청의 변경 파일을 구분하고 diff를 확인할 수 있습니다.
저장하지 않은 사용자 변경이나 파일 해시 충돌이 있으면 덮어쓰지 않습니다.
테스트·빌드 명령은 표시된 명령과 작업 폴더를 확인하고 매번 승인한 뒤 실행합니다.
명령은 PC의 셸에서 실행됩니다. 프로젝트에 필요한 실행 도구는 별도 설치되어 있어야 합니다.
되돌리기는 확장 실행 동안의 파일 수정만 대상으로 하며 터미널 변경은 복원하지 않습니다.

기존 Code Assistant 에이전트를 사용하려면
해당 에이전트의 웹 주소를 VS Code 설정 m365Agent.copilotUrl에 입력하세요.
설정을 바꿨다면 VS Code의 '개발자: 창 다시 로드'를 실행하세요.

연결 문제가 있다면
- 상단 더 보기(⋯) → 연결 진단에서 현재 페이지, 입력창과 최근 전송 단계를 확인하세요.
- 로그인 상태와 회사 계정의 Copilot 사용 가능 여부를 확인하세요.
- M365 화면 구조가 다르면 composerSelector/sendButtonSelector/responseSelector 설정을 조정해야 할 수 있습니다.
- 회사 정책에서 브라우저 자동화를 차단하면 이 방식은 작동하지 않습니다. 정책을 우회하지 않습니다.

실제 회사 테넌트 화면에서는 아직 검증하지 못했습니다.
로컬 모의 Copilot 페이지를 통한 실제 Edge 입력·응답 수집과 VS Code의 파일 편집·저장을 검증했습니다.
M365 데스크톱 앱과 직접 통신하는 공식 API 연동이 아니라, 웹 화면을 자동 조작하는 방식입니다.

읽은 파일 내용은 로그인한 M365 Copilot에 프롬프트로 전달됩니다.
다른 AI 서비스, 별도 개발자 서버, 텔레메트리로 전송하지 않습니다.
전체 동작·제약·개발 방법은 README.md를 참고하세요.
